# charity-idea
A repo for the charity idea.

## Premise
Optimisation and resource allocation prototype with the intention of encouraging youth extracurricular engagement, with complementary research into whether this could contribute to social mobility later in life.

By mapping local demand (initially academic, though this can be generalised) against existing opportunities, the model would be able to connect students to different types of opportunities, provide a high level view of the distribution of clubs (for funding and resource allocation), and could identify redundancies. It will be approached using graph theory.
